CS 4420 ASSIGNMENT 5

COMPILATION INSTRUCTIONS
-----------------------------------------------------------------------------------------------------------------------------------
After this file is accessible on your machine, you may compile it by using "g++ -Wall Assignment5.cc" and run it using 
"./a.out input_file Algorithm Quantum", where input_file is the file you are using for input,
algorithm is the algorithm you want to use, and quantum is the time quantum used if the algorithm selected is RR.

TEST CASES
-----------------------------------------------------------------------------------------------------------------------------------
The test cases I used within this project are included in this repository, labeled as input1.txt, input2.txt, and input3.txt. I used these files because
I wanted to test different numbers of processes and different burst times. Input 1, as well as the other test cases, are in the form of Number of 
processes at the top, followed by the actual process data (see below).
